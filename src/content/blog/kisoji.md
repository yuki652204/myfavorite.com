奈良井宿から妻籠宿へ歴史街道を巡る。

![奈良井宿](/images/kisoji/PXL_20260425_narai.jpg)

## 1日目コースタイム
- 新宿駅 → 塩尻駅 → 奈良井駅: 2時間30分（特急あずさ）
- 奈良井宿 → 南木曽駅 → バス → 妻籠宿: 40分
- 南木曽駅 → 特急しなの → 名古屋: 1時間
- 名古屋 → 岐阜駅 30分 → カプセルホテル

## 2日目コースタイム
- 伊奈波神社 → 長良川 → 川原町の古い町並み → 岐阜駅 → 名古屋
- 名古屋 → 熱田神宮 → 栄 → 錦 → 名古屋駅 → 品川駅

![南木曽看板](/images/kisoji/PXL_20260425_nagisokannban.jpg)

今回は木曽路をめぐってきました。馬籠宿にはいったことがあったのですが奈良井や妻籠にいってみようと思った次第であります。ネイティブな建物が多くありインバウンドもすごいですね。わたし以外の観光客は8割は外国人という感じです。

![ヒノキの橋](/images/kisoji/PXL_20260425_hasi_narai.jpg)

家屋や店舗の軒先の作り方や材料のこだわりが見受けられました。木曽ヒバ、木曽ヒノキなど、御用林もあるそうです。奈良井と妻籠は信濃の国であり馬籠は尾張の国のようです。

![妻籠宿](/images/kisoji/PXL_20260425_tumago.jpg)

妻籠から馬籠間は8キロくらいなので日が長い時期だと1日で東京から奈良井→妻籠→馬籠まで巡れるかと思います。一泊二日が望ましいですね。わたしは岐阜のサウナカプセルで泊まることにしました。朝食付きで4400円と破格です。飛騨牛のひつまぶしが絶品でした。

![古い町並み](/images/kisoji/PXL_20260425_huruimatinami.jpg)

たまたま通りすがりにあった伊奈波神社は由緒ある神社らしくとても趣のある神社でした。郊外には古い町並みが残っていて情緒があります。格子をつかった壁が印象的です。

## 名古屋

![熱田神宮](/images/kisoji/PXL_20260426_atutashain.jpg)

名古屋に来るのは2回目です。まず熱田神宮が有名らしいのでいってみました。天気も良いこともあり賑わっておりました。はじめて名古屋のひつまぶしを食べましたがこれも絶品です。熱田うなぎ天というお店です。次回は矢場とんです。

![ひつまぶし](/images/kisoji/PXL_20260426_hitumabusikimoiri.jpg)

![トチのテーブル](/images/kisoji/PXL_20260426_table.jpg)

## 感想

このまえの日本平といいわたしの行く観光地は外国人だらけでびっくりします。よくもまあ調べて慣れない電車に乗ってくると感心してしまいます。古い町並みなどOLD STYLEは世界共通で関心があるのだなと思いました。
